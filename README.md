# Documents

This repository serves as a centralized collection of **teaching materials, lecture notes, and hands-on laboratory exercises** used in courses related to:

- Computer Networks  
- Network Programming
- Network Security
- Confidence & Security of Information Systems 
- System administration and maintenance

The materials are designed to support **both theoretical understanding and practical skills**, and are primarily used for academic teaching, demonstrations, and guided self-study.
